# 🚀 موشک موزیک — نسخهٔ ویندوز (Electron + TDLib)

پلیر موزیک تلگرام برای ویندوز — همان برند و امکانات نسخهٔ اندروید، ساخته‌شده با Electron و TDLib (`tdl` + `prebuilt-tdlib`).

## ✨ امکانات

- **ورود**: شماره تلفن / کد تأیید / رمز دو مرحله‌ای / **QR Code**
- **اسکن**: عمق ۵۰ / ۱۰۰ / ۳۰۰ / همهٔ چت با پیشرفت زنده
- **استریم مستقیم**: پخش بدون دانلود کامل (بازه‌های ۵۱۲KB با `readFilePart`) + fallback دانلود کامل
- **کتابخانه**: تب‌های آهنگ‌ها / اسکن / پلی‌لیست / فیوریت / دانلودها / کانال‌ها / چت‌ها
- **پلی‌لیست‌های سفارشی** و **فیوریت**
- **کانال‌ها**: اسکن کامل / دانلود کامل کانال با یک کلیک
- **پخش پس‌زمینه** + کنترل مدیا ویندوز (MediaSession) + تری
- **ویژوالایزر زنده**، تم روز/شب، ۷ رنگ اکسنت، **دوزبانه فارسی/English**
- مدیریت پروکسی، لاگ زنده، کلید API شخصی

## 🔧 بیلد محلی

```bash
cd windows
npm install
npm start          # اجرا
npx electron-builder --win nsis portable   # خروجی در dist/
```

پیش‌نیاز: Node.js 20+
